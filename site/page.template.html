The free core

One click, one hotkey, one interval you control.

Press Start, or the hotkey, from anywhere — the window doesn't need focus. Clicks land wherever the cursor already is, on an interval you set down to the millisecond.

  • A global hotkey (F6 by default, yours to reassign) starts and stops it from inside any other window
  • Interval as low as 1 ms, or a random range so a long run doesn't land on the same beat every time
  • Runs until you stop it — there's no separate "session length" to configure
Image detection

Some buttons take a second to show up. This waits for them.

Drag a box around the button, icon, or bit of colour you're waiting for — right from the step editor, no separate screenshot tool. Auto Clicker checks the screen against that picture several times a second and only clicks once it's actually there.

  • Wait for image pauses a script until the target appears, up to a timeout you set
  • If image branches instead — one set of steps when it's found, a different set when it isn't
  • A confidence threshold (50–100%) keeps a match working even if the button moves a pixel or the game re-renders it slightly differently

Sequences

Chain clicks, waits, loops and conditions into a real script.

The Sequence tab builds a small tree of steps instead of one repeated action — click here, wait, loop, check what's on screen, then decide what happens next.

  • Loop a fixed number of times, or until you stop it
  • Branch with If image or If pixel, each with its own Then and Else steps
  • Save a script to a file and load it back later — or hand it to someone else
Beyond one point

A route of points, not just a single spot.

Switch "Click at" to a list, and Auto Clicker clicks each saved point in order before starting over — useful for anything spread across a few fixed spots on screen.

  • Add a point by clicking Add — the picker steps out of the way so your very next click marks the spot
  • Reorder or remove points without rebuilding the route
  • Pair it with a random interval so a repeating route doesn't land on the same rhythm every pass

What it doesn't do

No account. No licence key. No telemetry.

Every feature on this page — multiple points, random intervals, sequences, image detection, saved profiles — is unlocked from the first launch. There's no Pro tier waiting behind a key, because there isn't a Pro tier.

  • No account, no login, no server it talks to
  • Nothing is collected, logged remotely, or phoned home
  • One .exe; nothing installs a background service
